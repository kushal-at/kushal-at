## Selected Work

### WalkNext — Offline-First Walking Tracker

A privacy-first Android application designed for 100% offline step and fitness tracking without telemetry, external servers, or ads.

- **Architecture**: Implements MVVM with Android Architecture Components, reactive state management via Kotlin Coroutines and StateFlow, and local caching through Room Database.
- **Core Capabilities**: Hardware-based step sensor binding, real-time pace and GPS distance calculation, calorie burn estimation, and full history export to CSV.
- **Privacy Model**: Zero network permissions declared; all telemetry and user data remain on-device.
- **Stack**: `Kotlin` &middot; `Jetpack Compose` &middot; `Room DB` &middot; `MVVM` &middot; `Coroutines`
- **Links**: [Repository](https://github.com/kushal-at/WalkNext) &middot; [Releases (APK)](https://github.com/kushal-at/WalkNext/releases/latest)

### Polaris — Neuro-Symbolic Enterprise Policy Agent

An enterprise policy reasoning agent that combines large language models with a deterministic rule engine to eliminate hallucinations in regulated HR environments.

- **Architecture**: Decouples natural language intent extraction from decision logic. Query semantics are mapped into structured rule constraints evaluated by an isolated rule engine.
- **Core Capabilities**: Deterministic policy evaluation, automated conflict resolution with escalation paths, and immutable JSON audit trails for compliance reporting.
- **Deployment**: FastAPI service containerized with support for local, air-gapped LLM runtimes.
- **Stack**: `Python` &middot; `FastAPI` &middot; `Neuro-Symbolic Engine` &middot; `Local LLM`
- **Links**: [Repository](https://github.com/TechiestGeeks/Polaris)

### FarResume — Client-Side ATS Resume Builder

An in-browser resume builder that formats and exports ATS-compliant documents with live preview and client-side processing.

- **Architecture**: Zero-backend single page application. All generative optimization calls execute client-side via user-supplied API keys stored strictly in session memory.
- **Core Capabilities**: Real-time bullet-point and summary optimization via OpenRouter API, A4-paginated PDF rendering via `html2pdf.js`, and dual light/dark themes.
- **Stack**: `JavaScript (ES6+)` &middot; `Vite` &middot; `Vanilla CSS` &middot; `OpenRouter API` &middot; `html2pdf.js`
- **Links**: [Repository](https://github.com/kushal-at/FarResume) &middot; [Live Demo](https://ai-resume-builder-vite.vercel.app/)

### Pizza Palace — Interactive Food Ordering Application

A dynamic web application featuring an interactive pizza customizer, live cart state machine, and administrative dashboard.

- **Architecture**: Component-driven vanilla JavaScript application built on top of Vite, utilizing HTML5 Canvas for dynamic visual composition and LocalStorage for state persistence.
- **Core Capabilities**: Real-time layer composition on canvas as toppings are selected, dynamic item pricing calculation, slide-over order drawer, and administrative queue management.
- **Stack**: `JavaScript (ES6+)` &middot; `Vite` &middot; `HTML5 Canvas` &middot; `Vanilla CSS` &middot; `LocalStorage`
- **Links**: [Repository](https://github.com/kushal-at/PizzaPalace) &middot; [Live Demo](https://restaurant-demo-s776.vercel.app)
